# Archive — Shenry60 + HisMajesty0225

Created 2026-10-16. Private archive in estibancreations-svg.

## What this archive is

- `shenry60/` — actual preserved text source from `shenry60/Bing-Chat-Project`
  (`BingChat-main (1).zip`), extracted 2026-10-16. See `shenry60/README.md`.
- `inventory/hismajesty0225-inventory.md` — inventory-only record of the 39
  HisMajesty0225 repos pulled via the temporary-public workflow.
  Root file listings (names/sizes) + commit lists only. File contents were
  NOT pulled for HisMajesty0225 repos, so this archive does NOT contain
  their code. Do not treat this inventory as a full backup of those repos.
- `inventory/estibancreations-comparison.md` — name-level comparison against
  the signed-in `estibancreations-svg` account (22 repos).

## What was NOT preserved

- HisMajesty0225 file contents, zips, PDFs, images, or full git history.
  Only listings + commit messages are recorded here.
- Shenry60 binary files from the zip: `.vs/` Visual Studio cache files,
  `*.xlsx` sample outputs, `assets/cli-screenshot.png`. Listed in
  `shenry60/README.md` as excluded. The original zip itself is not stored
  here as a binary.
- Sensitive files were deliberately NOT copied: the W-9 / W-8BEN PDFs from
  `Steven_Henry_AI_System_Brain`, the `.env` from `T.H.E.LM.A.`, the
  `debug.keystore.base64` from `GrantOS-`, and any keys. Their existence
  is noted in the inventory only. Do not re-add them.

## Security notes carried forward

- `T.H.E.LM.A.` had a `.env` while public. Private-again does NOT undo
  exposure or remove it from git history. Rotate any real keys in it.
- `Steven_Henry_AI_System_Brain` had `W-9 copy.pdf` + `STEVEN HENRY W-8BEN
  copy.pdf` while public. Purge from all history, do not just delete the
  current files. Treat identifiers as exposed.
- `GrantOS-` had `debug.keystore.base64` while public. Low-risk for debug,
  remove/rotate if ever used for a release.
- `VisionWeaver-Revision-Hub` latest commit message mentions a fallback
  Runway API key. Not verified whether a real key is in the diff.

## Deletion guidance

- No account or repo was deleted to make this archive.
- GitHub account deletion is done by the account owner in GitHub
  settings, is irreversible, and should only happen after a verified
  full backup with history — not on the basis of this inventory alone
  for HisMajesty0225.
- For Shenry60: this archive preserves the Bing-Chat text source, but
  the exhaustive Estiban log sweep for Shenry60 / migration evidence
  was still not done at archive time.
