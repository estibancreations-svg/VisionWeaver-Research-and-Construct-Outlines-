# EC PUNCH LAB — AI Production Testing & Benchmarking

**Purpose:** Use repeatable short-drama/novella scenes to test 7Art, Runway, and emerging tools against one brief under fair conditions. Punch Lab is a testing and research workstream; StoryWorks is the production and revenue module.

## Repeatable benchmark

Use the same 9:16 test scene, script, reference characters, wardrobe, location, audio requirement, duration target, caption requirements and production budget across candidates. Record unavoidable engine differences. No fabricated test scores.

| Criterion | Weight |
|---|---:|
| Character continuity | 20% |
| Photorealism and motion | 20% |
| Story/prompt accuracy | 15% |
| Audio and lip-sync | 15% |
| Scene consistency | 10% |
| Speed and reliability | 10% |
| Cost per accepted usable second | 10% |

Rate each criterion 0–5 with evidence. Weighted score = sum(weight × rating / 5). **Commercial rights are a hard pass/fail gate**, not a negotiable score. Also gate for watermarks, sponsor claims and distribution rights.

## Candidate register

| Tool | Role | State |
|---|---|---|
| Runway | Cinematic production benchmark | Account, model, costs and integrations to verify |
| 7Art | Experimental short-drama generator | Rights and current capabilities to verify |
| There’s An AI For That | Discovery directory | Not an engine |
| Unnamed free-video candidate | Daily limits / usability test | Identity and licensing unverified |

Never infer 100 usable daily exports from promotional claims. Test daily limits, duration, export quality, resolution, stability, identity, generation speed, watermark, rights and true correction cost.

## Publishing testing outcomes

Case studies and tool comparisons require access/rights review. Do not imply vendor sponsorship or official partnership. Feed accepted routing recommendations into StoryWorks via a versioned change request and Architect approval.
