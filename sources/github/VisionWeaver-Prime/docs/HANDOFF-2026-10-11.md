## Deploying safely (for the next session)
- The cloud shell cannot push to GitHub or reach vercel.app or supabase.co. Use the GitHub, Vercel and Supabase connectors.
- Push app parts first and `manifest.json` last. A build between those pushes can show ERROR; that is expected, and the last good deployment stays live.
- Verify the result by fetching the live `app.js` and comparing it with the local build.
