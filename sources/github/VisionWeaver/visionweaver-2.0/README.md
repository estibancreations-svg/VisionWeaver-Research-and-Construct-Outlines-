# VisionWeaver 2.0
Built October 26, 2026, on Steve's order. One unified system, replacing the v1 build (archived at `visionweaver/archive/v1.0-pre-rebuild/`).

## Launch
Open `index.html`. The boot screen offers two launches:
- **Blank System — New User**: clean workspace, auto-created; the operations walkthrough starts here.
- **Demo — Existing Work**: the work already done (Fireside Ep 1 at its QC gate, Crossroads, books, queue) loaded to finish inside the system.

State persists per mode in the browser (localStorage). Export produces a JSON copy of the workspace.
