   FULL YOUTUBE UPLOAD PACK PROMPT (Copy–Paste)

BEGIN PROMPT

You are a YouTube SEO expert who creates viral upload packs.
Your job is to take the user's inputs and produce the BEST possible metadata for YouTube in
2025.



   STEP 1 — WAIT FOR USER INPUT

Ask the user to provide:

    1. 1–3 MAIN KEYWORDS for the video

    2. Full video SCRIPT (optional but recommended)

After receiving that, generate ONLY:

   3 Viral Title Options

Create 3 extremely high-CTR titles based on:

    •   Curiosity

    •   Emotional impact

    •   Urgency

    •   Searchability

    •   Suggested-feed optimization

Keep each title under 65 characters.

Stop and WAIT for user to choose the title they like.
Do NOT generate anything else yet.



   STEP 2 — AFTER USER SELECTS A TITLE

When the user picks one title, generate the full upload package:
1. Final Selected Title

Rewrite if needed for max CTR while keeping the meaning.



2. Viral SEO Description (200–300 words)

Must include:

   •   Hook in first 2 lines

   •   Main keywords naturally included

   •   2025 SEO formatting

   •   Bulleted “What You’ll Learn”

   •   Call to action for comments + subscribe

   •   Emotional tone + storytelling elements



3. Hashtags (10–15)

Mix of broad + niche related to the chosen title + keywords.



4. 500-Character Tag Block

A single comma-separated list (NOT hashtags):

   •   All keywords

   •   Synonyms

   •   Related search intents

   •   Trending wording

   •   YouTube Suggested-friendly phrases

Must be under 500 characters.



5. Pinned Comment

Engagement-optimized.
Should invite viewers to share their experience and encourage replies.



6. Thumbnail Ideas (4 styles)

Generate 4 thumbnail concepts based on:
   •    High CTR psychology

   •    Emotional reaction

   •    Clean composition

   •    Strong minimal text

   •    Clear color contrast

Each should include:

   •    Layout description

   •    Text on thumbnail (2–4 words max)

   •    Background idea

   •    Emotional tone



RULES

   •    ALWAYS optimize for Browse + Suggested traffic first.

   •    Keep all text easy to read on mobile.

   •    Titles must be optimized for both CTR and SEO.

   •    Thumbnail text must be 2–4 words only.

   •    Never exceed 500 characters in the tags section.

   •    Make everything sound powerful, emotional, and shareable.



END PROMPT

   4.      App 4: Robert Tech Tool Voice – Text-to-Speech
        Story Narrator
Purpose:
Robert Tech Tool Voice is an AI-powered app that converts text-based story scripts into natural-
sounding audio. Users can input dialogue, then assign voices to each speaker using Google
Studio’s free voice models. The app enables a seamless conversion of written content into
spoken words, ideal for animators, storytellers, and content creators.

    Left Column – Script Input
1. Script Text Box
    • A multi-line text box where users input their story script.
    • Users can format dialogue like this:
    • [Speaker 1: Hello, how are you?]
    • [Speaker 2: I'm good, thanks! What about you?]
    • [Speaker 1: I'm doing great, excited to see you.]
    • ...
    • Alternatively, it can be more condensed:
    • Speaker 1: Hello, how are you?
    • Speaker 2: I'm good, thanks! What about you?
2. Text Formatting
    • Auto-Detect Speakers: The app automatically detects and maps each speaker to the
        respective voice model.
    • Dialogue Validation: Ensures each speaker is properly formatted with a name and text,
        prompting an error message if any speaker tag is missing.
    • Option to Add More Speakers: Users can manually add or remove speaker lines and re-
        map them.

    Right Column – Voice Mapping & Settings
1. Voice Mapping
    • For each speaker in the script, the app maps them to a default free voice model from
       Google Studio (or any other free voices available).
           o Example:
                  ▪ Speaker 1 → Voice Model: “English – Female”
                  ▪ Speaker 2 → Voice Model: “English – Male”
    • Auto-Suggest Speaker Names: Based on the script input, the app can auto-suggest
       speaker names (like Speaker 1 “’Tom, Speaker 2””Marry, etc.), but users can reselect
       speakers from voice model of google
2. Voice Customization
    • Each voice model comes with basic controls that users can modify:
           o Pitch Control (Increase/Decrease voice pitch)
           o Speed Control (Adjust speech speed: Slow, Normal, Fast)
           o   Volume Control (Increase/Decrease volume of voice output)
            o Emotion Selector: Options like happy, sad, angry, surprised (depending on the
               voice model).
            o Voice Tone & Accent Options: If available, toggle between different accents or
               tonal qualities.
User can preview voice directly from the "Voice Selection" area for each dropdown . This lets
user hear a sample of the voice before committing to generating the entire audio script.

3. Voice Clone Option
Each speaker has an optional “Clone Voice” feature:
    •      Clone Voice button → Opens a pop-up modal:
           o Upload Voice Sample (.mp3/.wav) (30–60 seconds recommended)
           o User'll first click "Analyze Voice. AI analyzes tone, pitch, and speaking style.
           o Generates a custom voice model (using a free or compatible local model).
           o User assigns a name to the new voice (e.g., Emma Clone, Hero Clone).
           o Once created, it appears under the Voice Selection Dropdown as:
                   ▪   “   Emma Clone (Custom)”
           o   Voice samples are stored locally or in the user’s workspace for future use.
           o   User can preview any pre-built or cloned voice directly from the "Voice
               Selection" area. This lets you hear a sample of the clone voice before save.
           o   Save Voice: Once user've previewed and approved the clone, user can click
               "Save Voice" to add it to your library.

   •   Users can manage cloned voices via Voice Library:
           o Preview cloned samples
           o Rename or delete voice models
           o Mark favorite voices
4. Audio Preview
    • Each speaker line can be previewed individually:
           o        Preview Voice (for single speaker)
   •   Full script playback preview:
           o       Preview Full Story (combines all voices)

   Advanced Voice Features
   • Custom Voice Settings Preset:
      Save a speaker’s voice + settings as a preset for future scripts.

3. Preview & Adjustments
    • A Preview Button to listen to the generated voice output for each speaker before final
        rendering.
    • Auto-generate voice for script: As the user pastes the text, the voices will be mapped
        and can be previewed with a simple Play button for each speaker’s dialogue.
4. Add Background Music or Sounds (Optional)
    • Users can add background audio (like light music or ambient sound effects) to the
        generated dialogue clips.

1. Generate Audio
    • A large red button labeled “Generate Audio” to start processing the entire script and
        generate the voice clips.

2. Download Audio
    • Download All Audio button: Once the speech is generated, users can download the
        entire script as one audio file (e.g., Story_10Nov2025.mp3).
    • Individual Speaker Files: Alternatively, users can download the audio for each speaker
        separately:
            o Speaker_1_10Nov2025.mp3

    • Additional options to tweak the intonation (rise and fall of the voice) and volume for a

    • Users can save their progress, come back later, and resume mapping voices or editing
        the script without losing data.
