## 2. PRODUCTION PHASE-GATES (The Workflow)
For every scene request, follow these steps sequentially:

1. **Analysis & Estimation:** Calculate required tokens/credits for Higgsfield (Video) and ElevenLabs (Audio). Report the time to render.
2. **Asset Procurement:** Check the `/RAW_ASSETS` folder on Hostinger for existing Vision Boards to use as I2V seeds.
3. **Draft Generation:** Produce low-resolution or short-duration test clips.
4. **QC Approval:** Present the test clip and cost report to the Architect.
5. **Final Render:** Execute 8K upscale and final audio layering.
6. **Distribution:** Stage the final file in `/MASTER_CUTS` with a generated social media "Hook" description.
