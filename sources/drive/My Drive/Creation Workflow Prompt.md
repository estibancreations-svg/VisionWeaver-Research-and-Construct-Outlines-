### The Workflow (4 Steps)
#### Step 1: Create Project in MakeUGC
Go to MakeUGC.ai and create new project.
Settings to configure:
Select Sora 2 feature (cinema-quality generation)
Adjust ratio (16:9 for standard commercial, 9:16 for social, 1:1 for square)
Set length (15s, 30s, 60s depending on campaign needs)
#### Step 2: Generate 6-Scene Structure with ChatGPT
Take your ad concept and input it into ChatGPT with the prompt below.
Your ad concept example:
"Apple-style product reveal for wireless earbuds, emphasis on minimalist design and seamless technology integration"
#### Step 3: The Cinematic Ad Prompt
Copy and paste this prompt into ChatGPT, replacing {{IDEA}} with your ad concept:
Plain Text
You are a cinematic ad storyboard generator.

INPUT (one idea only): "{{IDEA}}"

TASK:
Create a 6-frame cinematic ad (6 still frames) that communicates ONE core idea only. No subplots, no extra messages.

RULES:
- Keep the same main subject + setting across all frames.
- Each frame must advance the same idea (escalation → reveal → payoff).
- Write like a director: what we see + camera + lighting + action.
- No brand names unless included in the idea.
- No dialogue. No voiceover. No text overlays.
- Consistent visual style across all 6 frames.
- Output ONLY the JSON below.

OUTPUT JSON:
{
  "idea": "{{IDEA}}",
  "style_bible": {
    "genre": "",
    "mood": "",
    "color_palette": "",
    "camera_language": "",
    "lighting": "",
    "texture": ""
  },
  "frames": [
    { "id": 1, "shot": "", "camera": "", "lighting": "", "action": "", "key_detail": "", "negative": "" },
    { "id": 2, "shot": "", "camera": "", "lighting": "", "action": "", "key_detail": "", "negative": "" },
    { "id": 3, "shot": "", "camera": "", "lighting": "", "action": "", "key_detail": "", "negative": "" },
    { "id": 4, "shot": "", "camera": "", "lighting": "", "action": "", "key_detail": "", "negative": "" },
    { "id": 5, "shot": "", "camera": "", "lighting": "", "action": "", "key_detail": "", "negative": "" },
    { "id": 6, "shot": "", "camera": "", "lighting": "", "action": "", "key_detail": "", "negative": "" }
  ]
}

What this prompt does:
Converts your ad idea into a structured 6-frame commercial with consistent visual style, camera work, lighting, and narrative flow optimized for Sora 2.
#### Step 4: Paste into MakeUGC and Generate
Copy the JSON output from ChatGPT and paste it into MakeUGC.
What happens:
Sora 2 generates all 6 scenes

Applies professional camera movements

Delivers commercial-grade quality
Generation time: 5-10 minutes
