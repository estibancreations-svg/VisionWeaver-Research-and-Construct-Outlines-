# Partner Portal — Job Lifecycle State Machine (MVP)

## States
1. CREATED
2. DISPATCHED
3. OFFERED
4. ACCEPTED
5. EN_ROUTE
6. ARRIVED
7. IN_SERVICE
8. COMPLETED_PENDING_PROOF
9. PROOF_SUBMITTED
10. APPROVED_FOR_PAYOUT
11. PAID
12. CLOSED

## Exceptional States
- DECLINED
- EXPIRED
- CANCELED
- DISPUTED
- ADJUSTED
- FAILED

## Key Transitions
- CREATED → DISPATCHED → OFFERED → ACCEPTED|DECLINED|EXPIRED
- ACCEPTED → EN_ROUTE → ARRIVED → IN_SERVICE → COMPLETED_PENDING_PROOF → PROOF_SUBMITTED
- PROOF_SUBMITTED → APPROVED_FOR_PAYOUT|DISPUTED → PAID → CLOSED
