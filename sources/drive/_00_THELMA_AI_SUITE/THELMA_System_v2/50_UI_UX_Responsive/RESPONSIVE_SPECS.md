# Responsive UI/UX (Desktop/Tablet/Mobile)

Breakpoints:
- Mobile <= 480px
- Tablet 768–1024px
- Desktop >= 1280px

Rules:
- Mobile-first for accept/decline, arrive/start/complete, proof upload, payout check
- Tables become cards on mobile
- Touch targets >= 44px; keyboard + focus + labels
