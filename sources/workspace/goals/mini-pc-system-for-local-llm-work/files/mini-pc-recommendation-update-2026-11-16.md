## TV as the full-time display

- Standard setup: mini PC → HDMI → TV. Works as an everyday display.
- 4K TV is much easier on text than 1080p (sharper, more screen real estate).
- Use the TV's PC or Game mode: cuts input lag and disables overscan (edge cropping) and heavy post-processing.
- Sound comes through the TV speakers over HDMI.
- NOT portable: the setup lives where the TV lives. If TV access is unreliable, the portable monitor keeps Build A mobile.
- Peripherals: a mini PC needs a keyboard and mouse/trackpad. Check what he already owns before buying; no peripheral cost is included above.

## When another build wins

- B (MacBook Air) wins only if portability matters most: carry-it-everywhere, screen + battery built in, no TV or desk needed. Trade-off: 24GB RAM (less than A's 32GB) and the highest single-item price.
- C wins only if lowest spend is the top priority. Trade-off: weakest for LLMs (24GB, weaker chip).
