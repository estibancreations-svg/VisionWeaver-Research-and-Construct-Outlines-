# Hill-style public-domain speaker channels

Goal ID: goal_bdd290467fe7

## Description
Create Hill-style motivational channels for 11 public-domain speakers, using original in-style-of scripts rather than the speakers' own works. Each channel follows the copied format of 45–50 minute long-form videos plus Shorts and posts, with a disclaimer that the work is original and not an official speech.
