# Supabase uncapped connection

Goal ID: goal_6bfcc05fdf3d
Goal slug: supabase-uncapped-connection

## Description
Connect Supabase to Muse with no project, read-only, or feature limits so it can list projects, query databases, run migrations, and work with Edge Functions, logs, and branching. The connection is being built in chat rather than via the Connectors UI, and the next step is the user creating an uncapped Personal Access Token in the Supabase Dashboard and entering it on the secure page, without pasting it in chat.
