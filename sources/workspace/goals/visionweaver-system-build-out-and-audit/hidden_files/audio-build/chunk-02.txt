Part A — Directives D5–D6 D5 — Character continuity — the board system Directive: No character, scene, room, or angle ships without a board. Every character board carries: turnaround (front / side / back) plus a 360-degree strip, variation study, close details, spec sheet, anchor name, likeness ladder with correction callouts, kinesic callouts, and body-type anchor. Both locked variants of a character — for example glasses and non-glasses — are boarded separately; a variant is never “fixed.” How to create it: Generate from the locked portrait reference. Before saving any generated frame, ask the retention question: “Should this image be referred to as [ANCHOR NAME]?” Record drift at save time, not at render. Required return: The board image(s) plus the written board: spec sheet, ladder, and callouts. Gate: A character with no board cannot enter a scene board, a thumbnail, or a render. D6 — Environment standard Directive: Every room or setting board carries four panels — Wide Establishing, Medium Texture, Key Prop/Detail, Lighting Reference — plus multi-angle coverage of the same room and a floor plan with blocking. How to create it: Build the set board first, then scene boards that reuse only boarded angles. A position change in a setting must already exist on a board. Required return: The set board image, floor plan, and angle list. Gate: No scene ships in an unboarded room or from an unboarded angle. Part A — Directives D7–D8 D7 — Prompt standard Directive: Every board ships with two machine forms: Type 1, a Master JSON Payload (visual standard: aspect ratio, color science, dynamic range, frame rate, audio routing), and Type 2, a Markdown System Directive (art logic: physics rendering, kinesic detail, transition lock). How to create it: Attach both forms as the header of every character and scene board. Absorb new example batches into the template; never rebuild locked boards to absorb them. Required return: Both forms, present on the board, with transition locks recorded per beat in the shotdeck (Linear Snap / Dot 0.5s / True Black, or as re-picked). Gate: A board without its prompt header does not enter production. D8 — Crossroads production standard Directive: The Crossroads of Identity production standards govern this series and everything after it: pipeline order — Avatar Engineering → Worlds and Locations → Books and script → Locks and maps → Cast and avatars → Shot bible → Pictures → Motion → Narration booth → Sound and music → Edit → Deliver → Publish and social. Visual change every 8–15 seconds; pacing reset every 30–60 seconds; hook under 8 seconds with no branding opener; payoff at 70–85%; music 9–12 dB under voice; captions checked against the script; render and QC at the stated class; budget as cost per finished second; preview, verify, publish. Finished pieces ship clean — no raw production note burned into any frame. How to create it: Map each standard to the episode concretely in the production package, not as a generic list. Record render class and cost per finished second before rendering. Required return: The standards-mapping page of the production package, with every standard mapped to a concrete choice. Gate: No publish from an unverified render. No publish with a production note in frame. Part A — Directives D9–D10 D9 — Delivery format Directive: Print first, then the audio of exactly that, verbatim, right after. No synopsis plus a separate summary voice note — that pairing reads as repetition. Otherwise voice notes stay short (under about one minute), one pass, essentials only, never a full re-read, never duplicate recordings of the same text. Written replies stay tight; recaps use checklists. Analysis is deep, finite, and definitive. How to create it: Write the piece, then read that piece — not a summary of it. Verify each file exists before sending. Check each file's duration against its text length before shipping — and check content, not duration alone (see D12). Required return: The printed piece plus the matching audio file, verified present, with duration and content checked. Gate: No audio ships on a duration check alone. D10 — Funding gate Directive: Billing stays on hold until funding comes in. No paid render, paid tool, or paid work starts on assumption. Free work only until you say otherwise. How to create it: Plan every sprint in free-only form first: writing, free image generation, documents, boards, guide audio. Mark every render and publish step as funding-gated. State cost before any run, and enforce the ceiling. Required return: A sprint plan that states what is free and what is gated, with no gated step started. Gate: No render, no paid generation, no publish spend without your funding go-ahead. Part A — Directives D11–D12 D11 — Weekly engine and posting Directive: Weekly cadence: one 6–12 minute teaching plus one 45–60 second Short (single aphorism plus practice). Every episode ships a posting package: exact long title, Short beat sheet, two-paragraph description, exact safe tags, channels (YouTube: Estiban Creations; Instagram: Master_Your_Thinking), weekly calendar, posting checklist, and IP checklist. No posting day or time is invented. How to create it: Build the posting package as the last pages of the production package. Still-image posts (thumbnails, quote cards) may go live without a render; video waits for render. Required return: The posting package plus text-verified thumbnails (main 16:9 and Short cover), each with its text read back from the standalone file and confirmed exact. Gate: No video post without render plus QC preview pass. No post with unverified thumbnail text.
