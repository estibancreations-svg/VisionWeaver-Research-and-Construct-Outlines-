System 3 — Director Studio, the director control surface in the VisionWeaver repository What this system is: a control surface in the repository estibancreations-svg/VisionWeaver, folder apps/director-studio, version 7 in its README dated 30 September 2026, with version 8 parts in its source files and a version 8.1 frames fix dated 3 October 2026. Its stated production is one production only: Crossroads of Identity, Book 1 Convergence, Episode 1, The News. Its stated job is the place where Sire, the director, makes every decision in the pipeline, from the books and locks through pictures, motion, sound, the edit, delivery, and publishing. Departments bring finished work to the Directors Guild queue, and nothing moves until Sire decides. Two gates never move: key frames are approved before any video is made, and the word APPROVED is required before anything goes public. The build reads the episode's production records straight from the repository, so the page always matches them. The file index.html is a build output and is not committed; running build.py makes it. The live copy is published as a Claude artifact. Opened as a plain file, the page still works and saves to that browser only.
