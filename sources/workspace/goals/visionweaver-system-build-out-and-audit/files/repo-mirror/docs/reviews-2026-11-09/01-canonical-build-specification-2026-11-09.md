## 1. Directive Lock — D1 to D25

Locked as the system's specification. Overlap between the VisionWeaver 2.0 rules and D10–D12 is merged into a single wording in each directive. No new UI lineage is authorized without your explicit unlock of D23.

- **D1 One track at a time** — One project per track. Named goal, named lead, track name on every artifact. Cross-track is explicit links, never merges. Return: track sheet. Gate: no second track in the first track's thread.
- **D2 Hold-then-go** — Hold means proposal only. Nothing built, rendered, posted, moved, disconnected, or spent. Return: checklist with hold marked and next step named. Gate: explicit go per step.
- **D3 Originality lock (IP)** — Original characters, lines, titles, tags, thumbnails, branding only. Banned: Yoda, Grogu, Jedi, the Force, lightsaber, Star Wars, "This is the Way," and any borrowed franchise lore. Return: clean banned-term scan + open counsel review line. Gate: no publish without clean scan.
- **D4 Script spine** — Hook <8s → story → reframe → practice → payoff (70–85% of runtime). Titles name the lesson. Script is source; words do not change. Narration in ≤30s chunks. Return: full script verbatim with mode, lead, setting. Gate: nothing downstream before script exists; no render before approval.
- **D5 Character continuity** — Every character carries a board: turnaround + 360° strip + variation study + close details + spec sheet + anchor name + likeness ladder + kinesic callouts + body-type anchor. Variants boarded separately; never "fixed." Return: board image + written board. Gate: no board = no scene, no thumbnail, no render.
- **D6 Environment standard** — Every room carries four panels (Wide, Medium, Key Prop, Lighting) + multi-angle coverage + floor plan with blocking. Return: set board, floor plan, angle list. Gate: no scene from an unbordered room or angle.
- **D7 Prompt standard** — Every board carries Type 1 Master JSON Payload (aspect, color science, DR, fps, audio routing) and Type 2 Markdown System Directive (physics, kinesic detail, transition lock). Return: both forms on the board. Gate: no prompt header = no production entry.
- **D8 Crossroads production standard** — Pipeline order: Avatar → Worlds → Books/script → Locks/maps → Cast → Shot bible → Pictures → Motion → Narration → Sound → Edit → Deliver → Publish. Visual change every 8–15s; pacing reset every 30–60s; hook <8s; payoff 70–85%; music 9–12 dB under voice; captions checked against script; render/QC at stated class; budget as cost per finished second. Return: standards-mapping page. Gate: no publish from unverified render; no production note in frame.
- **D9 Delivery format** — Print first, then verbatim audio right after. Short voice notes (<1 min), one pass, essentials only. Return: printed piece + matching audio, duration and content checked. Gate: no audio on duration alone.
- **D10 Funding gate** — Billing on hold until funding. No paid render, tool, or work on assumption. Free-only until explicit go. Return: sprint plan stating free vs gated. Gate: no spend without go-ahead.
- **D11 Weekly engine and posting** — One 6–12 min teaching + one 45–60s Short per week. Every episode ships a posting package: exact long title, Short beat sheet, 2-paragraph description, exact safe tags, channels (YouTube: Estiban Creations; IG: Master_Your_Thinking), weekly calendar, posting checklist, IP checklist. Return: posting package + text-verified thumbnails. Gate: no video post without render + QC; no post with unverified thumbnail text.
- **D12 Approval gates and required returns** — Stage chain: outline → script draft → approval → production package → text-verified thumbnails → character and scene boards → verbatim guide audio → funding-gated render → QC preview → publish. Each stage returns a named artifact with a verification note. Gate: any stage stoppable by you at approval points.
- **D13 Balance rule** — Shadow side shown with cost accounting and redemption visible. Return: cost accounting + redemption beat in the script. Gate: no shadow without redemption; no light by pretending shadow is absent.
- **D14 Origin and cosmology** — Grounded in measured record (13.8B years, inflation, first light ~380k years, first stars, Milky Way, Sun, Earth, life, Laniakea, accelerating expansion). Epic feel only — no borrowed lore (D3). Framing: nothing before, everything at once, "as they became, so did they." Return: origin section + factual record. Gate: no mythic telling presented as measured fact.
- **D15 No-assumption rule** — Never assume an outcome. Mark every unconfirmed item unconfirmed in the artifact. Corrections propagate to every affected record. Return: open-decisions list in every package. Gate: unconfirmed item cannot be cited as fact.
- **D16 Version truth** — Canonical by Nov 9 baseline: C/B/A intended architecture (C Fullstack Master = application body; B VisionWeaver 2.0 = production engine; A vw3 = approved visual design crown). Director Studio 0.4.02 archived wrong-version. Prime is historical reference. Fingerprint-check any build against the locked navigation board before calling it canonical. Return: fingerprint match. Gate: no build called "the system" without match.
- **D17 Pre-production prediction gate** — No scene enters generation without a prediction record created before production begins: scene ID, boarded angles, weather, acoustics, lighting reference, movement complexity, dot-level tracking notes, continuity anchors, token-range estimate, time estimate, pass ceiling ≤2 before human review, look-and-feel statement. Return: prediction record. Gate: no run without it; a 3rd pass requires written approval.
- **D18 Forensic QC note** — Every QC check produces an append-only note: what was checked, against what source, method, result, checker, timestamp, approval. Duration alone is never QC. Content checks mandatory for audio, thumbnails, captions, boards. Return: note tied to the artifact. Gate: no stage advances on a partial check.
- **D19 Storage truth lock** — Production record lives in the verified Supabase project (ref TBD after Gate 0). UI state, localStorage, and chat are never truth. A local mirror is non-authoritative. Return: queryable record. Gate: no Phase 2 work on unverified connection; no "saved" without a record.
- **D20 Chain-of-custody and correction propagation** — Every approved artifact carries provenance: source, version, approver, timestamp, downstream dependencies. Corrections create a new version; history is not overwritten. Stale files are reopened. Return: audit trail per artifact; open-decisions list. Gate: no unconfirmed item cited as fact later; no correction left unpropagated.
- **D21 Free-first, Runway-at-quality routing** — Design, concept, writing, boards, thumbnails, guide audio run free-first. Once ideas are locked and you move to real constructed movies and publishing documents, generation and finishing route through Runway. Model routing: Gen-4.5 (photoreal generation, physical accuracy, prompt tracking); Act-Two (markerless performance capture — body, face, hands); Aleph 2.0 (multi-shot consistency, targeted edits to 30s at 1080p). Cost stated before every run; ceiling enforced; cost per finished second recorded. Return: model-choice + cost record per run. Gate: no paid run without funding go and a prediction record.
- **D22 Scale-ready roles and permissions** — Roles modeled now for 30–50 users and agents: Owner, Creator, Reviewer, Auditor, Executive, Counsel, Publisher, Agent. Permissions matrix in the record, not in UI copy. Every action attributed to a role and identity. Return: permissions matrix; action attribution. Gate: no approval/publish without role authority; no agent action without logged scope.
- **D23 No new front end** — No new UI lineage until Phases 1–4 are built and verified. C/B/A is the surface. Existing pages completed, not replaced. Director Studio and VisionWeaver 2.0 remain archived. Return: page change mapped to a pipeline need. Gate: no UI work approved unless it closes a named gap.
- **D24 Teaching ladder embedded** — Five tiers (7th grade → PhD/forensic) embedded in Resources, Assets and Knowledge, and Quality and Audit. Each tier carries lessons, exercises, rubrics, assessments. Forensic tier produces thesis-grade analysis, forensic audit, teachable curriculum. Return: tiered curriculum surfaces. Gate: untiered content cannot be published as curriculum.
- **D25 Lifelike and motion standard** — Render standard is lifelike and close to human, movement tracked at every dot, weather and sound accounted for, scene-by-scene prediction completed before production starts. Return: look-and-feel statement per scene in the prediction record. Gate: render that does not meet the stated look and feel is rejected at QC, not shipped.

## 3. Executive Summary

**What exists.** A detailed Avatar State contract, a rendered board interface at the 22 October Prime preview checkpoint, a working manual method (Season 1 proved it), and a set of consolidated architectural decisions from 1–2 November that the 9 November review places as the intended — but not yet verified — target.

**What does not exist.** A verified consolidated runtime. A production record under D19. A tested stage chain under D12. Board data as versioned records under D5–D6. A prediction layer under D17. A forensic QC note system under D18. A cost ledger under D10/D21. A persisted open-decisions register under D15/D20.

**What is blocked and why.** Shot 02 is HOLD until Avatar State passes. World State is behind Avatar State. 64-slot is behind camera-height calibration. No spend until funding and prediction. No new front end until Phases 1–4.

**The verdict.** Do not rebuild the interface. Build the pipeline underneath C/B/A, in gate order, and move the already-working creative method into it. Every hour spent on another front end is an hour not spent on the pipeline.

## 7. Data Schema (the production record)

Minimum viable schema under D19–D22. Namespaced vw_ to avoid collision with existing production_log, social_post_queue, social_connections, oauth_flow_state, ww_review_decisions, ec_connectors.

```sql
-- Roles and identity
create table vw_roles (
  id uuid primary key default gen_random_uuid(),
  user_id uuid not null,
  role text not null check (role in ('owner','creator','reviewer','auditor','executive','counsel','publisher','agent')),
  scope jsonb not null default '{}',
  granted_by uuid not null,
  expires_at timestamptz,
  created_at timestamptz not null default now()
);

-- Projects and episodes
create table vw_projects (
  id uuid primary key default gen_random_uuid(),
  slug text unique not null,
  title text not null,
  kind text not null check (kind in ('book','commercial','film','image','series','clip')),
  canon_version int not null default 1,
  registered boolean not null default false,
  created_at timestamptz not null default now()
);

create table vw_episodes (
  id uuid primary key default gen_random_uuid(),
  project_id uuid not null references vw_projects(id) on delete restrict,
  number int not null,
  title text not null,
  stage text not null default 'outline',
  unique (project_id, number)
);

-- Scripts: immutable once approved
create table vw_scripts (
  id uuid primary key default gen_random_uuid(),
  episode_id uuid not null references vw_episodes(id) on delete restrict,
  version int not null,
  body text not null,
  approved_by uuid,
  approved_at timestamptz,
  unique (episode_id, version)
);

-- Decisions register (D15, D20)
create table vw_decisions (
  id uuid primary key default gen_random_uuid(),
  project_id uuid not null references vw_projects(id) on delete restrict,
  question text not null,
  status text not null check (status in ('open','decided','blocked')),
  answer text,
  decided_by uuid,
  decided_at timestamptz,
  created_at timestamptz not null default now()
);

-- Boards: versions immutable; locked boards never edited
create table vw_boards (
  id uuid primary key default gen_random_uuid(),
  project_id uuid not null references vw_projects(id) on delete restrict,
  kind text not null check (kind in ('character','set','scene')),
  anchor_name text not null,
  version int not null default 1,
  locked boolean not null default false,
  spec jsonb not null,
  created_at timestamptz not null default now(),
  unique (project_id, kind, anchor_name, version)
);

-- Coverage sets (32 / 16 / 64)
create table vw_coverage_sets (
  id uuid primary key default gen_random_uuid(),
  board_id uuid not null references vw_boards(id) on delete restrict,
  profile text not null check (profile in ('32','16','64')),
  claimed_complete int not null default 0,
  total_slots int not null,
  manifest jsonb not null default '[]',
  status text not null default 'pending' check (status in ('pending','partial','approved'))
);

-- D17 prediction records
create table vw_prediction_records (
  id uuid primary key default gen_random_uuid(),
  episode_id uuid not null references vw_episodes(id) on delete restrict,
  scene_id text not null,
  angles_used jsonb not null,
  weather text, acoustics text, lighting_reference text,
  movement_complexity text not null,
  dot_tracking_notes text not null,
  continuity_anchors jsonb not null,
  token_range_low int not null, token_range_high int not null,
  time_estimate_minutes int not null,
  pass_ceiling int not null default 2 check (pass_ceiling <= 2),
  look_and_feel_statement text not null,
  created_at timestamptz not null default now()
);

-- D18 QC notes: append-only
create table vw_qc_notes (
  id uuid primary key default gen_random_uuid(),
  artifact_id uuid not null,
  artifact_kind text not null,
  check_type text not null check (check_type in (
    'banned_term_scan','script_to_audio_content','thumbnail_text_readback',
    'board_completeness','continuity_variant_match','clean_frame',
    'placement_disclosure','caption_vs_script','cost_ceiling','rights_present'
  )),
  checked_against text not null,
  method text not null,
  result text not null check (result in ('pass','fail')),
  checker_id uuid not null,
  created_at timestamptz not null default now()
);

-- D10 / D21 cost ledger
create table vw_cost_ledger (
  id uuid primary key default gen_random_uuid(),
  episode_id uuid not null references vw_episodes(id) on delete restrict,
  run_kind text not null,
  model text,
  seconds numeric,
  credits numeric,
  usd numeric,
  ceiling_usd numeric not null,
  approved_by uuid not null,
  idempotency_key text unique not null,
  created_at timestamptz not null default now()
);

-- D20 audit and provenance
create table vw_audit_events (
  id bigserial primary key,
```
